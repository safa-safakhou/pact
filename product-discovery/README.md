# Product discovery archive

**The authoritative design is now [PACT — Version 1](../docs/pact/README.md).**

The new package separates the product brief, game rulebook, account/connection specification, execution contract, social/evidence rules, privacy policy, and build acceptance checklist. It incorporates the founder’s latest decisions on multiple providers, PACT-hosted player-key runs plus MCP access, email/password accounts, cosmetic Gems, and no purchased gameplay advantage.

Numbered documents in this folder are historical research and proposals. They do not override the current specification. In particular, documents 32–34 no longer determine provider scope, execution, authentication, retention, or rule details.
