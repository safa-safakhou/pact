# 21 Integrated Task and Motion Planning

[Garrett et al., arXiv v1, October 2020; Annual Review 2021](https://arxiv.org/abs/2010.01083). Coverage: complete main body, pages 1–24 of 30, plus acknowledgments; references partly inspected. Figure labels extracted; layouts not exhaustively audited.

**Mechanism.** Combine discrete action sequencing with continuous parameter and trajectory constraints. Compare sequencing first, constraint satisfaction first and interleaved search; reuse both successful assignments and failure information.

**Evidence type.** Formal problem definition and taxonomy of existing algorithms, not a new head-to-head experiment.

**Limits and contrary evidence.** High-level plans often cannot be refined mechanically. Sampling or optimization failure usually does not certify impossibility. Separate constraint solvers can miss interactions; joint solutions face dimensionality and nonconvexity. Core scope assumes known state, deterministic actions and rigid-body geometry; uncertainty and learned models are extensions.

**Mission implication — inference.** Mechanical feasibility must influence cognitive planning. Independent implementation does not imply independent decisions. “Could not execute within budget” should remain distinguishable from “cannot execute.”

**Test suggested.** Compare one-way planning-to-action with bidirectional feasibility feedback, sharing the same skills; track repeated failures, planning cost and solved tasks.
