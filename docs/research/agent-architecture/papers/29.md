## 29 — FeUdal Networks for Hierarchical Reinforcement Learning

**Source/coverage:** Vezhnevets et al., [arXiv v2, March 2017](https://arxiv.org/abs/1703.01161v2), all 12 pages read. Figure layouts and derivations not independently audited; external supplementary media not reviewed.

**Mechanism:** A Manager proposes directions in learned latent state space; a Worker selects primitive actions using observations, recurrent memory, and goals. Manager and Worker receive different learning signals; Worker receives both intrinsic and environmental reward. Dilated recurrence preserves longer timescales. Perception is shared.

**Evidence:** Atari, four DeepMind Lab memory tasks, component ablations, and transfer across action-repeat rates. Several long-horizon tasks improve against recurrent baselines. Important counterexamples: flat LSTM performs better on Seaquest, Breakout, and Alien in reported comparisons.

**Limits:** Curves report the best five agents from large hyperparameter searches, rather than typical-run performance. Backpropagation horizons differ between systems. The transition-gradient argument uses an approximate model of Worker behavior. Action-repeat transfer requires explicit temporal adjustments and retraining; it is not transfer to unrelated games. Two levels are demonstrated; deeper hierarchies are proposed.

**Mission implication — inference:** Learned goals and memory at different timescales are credible candidates, not universal improvements. Compare typical-run results and total tuning cost; test whether sharing perception, gradient separation, goal representation, or temporal memory produces the gain.
