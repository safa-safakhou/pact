## 58 — Neural Simplex Architecture

**Source/coverage:** Phan et al., [arXiv v2, March 2020](https://arxiv.org/abs/1908.00528v2). Read main text and all three case-study appendices, PDF pp. 1–15 and 19–24. References sampled; proofs, code and videos not independently checked.

**Mechanism:** A neural controller proposes actions; a decision module switches to a verified baseline before leaving its recoverable region. An adaptation module learns from rejected proposals while the baseline controls the plant. A stricter reverse-switch condition reduces oscillation and returns control to the neural controller.

**Evidence:** Simulated pendulum, fixed-obstacle rover and linear glucose-control models. Rover retraining increased target arrivals from 865 to 970 of 1,000 trials while reducing unrecoverable proposals from 100 to eight. Targeted retraining outperformed substantially longer continuation of initial training.

**Limits/contrary evidence:** Assumes observable state, suitable dynamics/simulation and a valid baseline recovery region. Rejected actions require simulated counterfactual transitions. Pendulum and glucose controllers were deliberately undertrained; rover obstacles stayed fixed for numerical evaluation. Results do not establish timing budgets, robustness to arbitrary model errors or general game competence.

**Mission implication — inference:** Recovery and improvement can coexist: fallback need not permanently disable the stronger controller. But safe operation depends on verified interfaces and timely recovery, while learning useful behavior remains a separate challenge.
