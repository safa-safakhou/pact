## 45 — Hybrid Computing Using a Neural Network with Dynamic External Memory

**Source/coverage:** Graves et al., [Nature 2016](https://www.nature.com/articles/nature20101), published [21-page copy](https://web.stanford.edu/class/psych209/Readings/GravesWayne16DNC.pdf). Main pp. 1–5, methods pp. 7–11 and extended captions read; Table 1 visually inspected. Other image-only tables and separate supplement not reviewed; equations not independently verified.

**Mechanism:** A trained recurrent controller reads/writes an external memory matrix using content lookup, temporal links and allocation/freeing. Computational rules reside in weights; episode-specific variables reside in memory.

**Evidence:** Synthetic question answering, graph traversal/inference and reinforcement-learned block manipulation. Memory supports held-out graphs and postponed goal execution. Twenty training runs and LSTM comparisons provide evidence beyond individual demonstrations.

**Limits/contrary evidence:** The celebrated 3.8% question error is a best-run result; its configuration averages 20.8% across runs. The alternative DNC configuration averages 16.7%. Curricula are essential outside question answering; earlier lessons need replay. Inputs are structured, shortest-path actions are legality-masked, and tasks are small. Exact temporal links cost quadratic memory/computation; sparse approximation is separately demonstrated.

**Mission implication — inference:** Persistent variables and learned procedures can be separated without an explicit symbolic planner. Test memory reliability, overwrite behavior, scaling and training variance; external storage alone does not guarantee reasoning or competent control.
