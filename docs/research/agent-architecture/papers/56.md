## 56 — Neural Production Systems

**Source/coverage:** Didolkar et al., [NeurIPS 2021 / arXiv v3, March 2022](https://arxiv.org/abs/2103.01937v3), main pp. 1–10 and appendix pp. 15–26 read. References partly read; figure imagery and implementation not independently audited.

**Mechanism:** Object slots hold changing entity states; learned rule modules transform selected slot pairs. Attention binds rules to primary/context entities. Sequential updates favor sparse events; parallel updates allow more entities to change together.

**Evidence:** Toy transformations, physical prediction, object tracking and action-conditioned Atari world models. Sequential rules work better for infrequent ball interactions; parallel rules work better for stacked shapes. Some experiments compare many seeds, others only two or three.

**Limits/contrary evidence:** These are prediction/reconstruction results, not agents learning to win games. Arithmetic-rule selection receives both input and desired-output coordinates, limiting its interpretation as autonomous reasoning. Object encoders, slot counts, rule counts and update schemes require choices. More rules can hurt, and sequential stages increase compute. Choosing sequential versus parallel based on the environment is currently a designer decision. Generic GNNs need not all have the dense/static form of these baselines.

**Mission implication — inference:** Factor entity memory from reusable interaction knowledge as one candidate world-model design. Validate whether improved prediction actually improves planning and control, especially under missed objects, simultaneous interactions and changing rules.
