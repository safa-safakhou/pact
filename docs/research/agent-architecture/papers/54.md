## 54 — Continual Learning Through Synaptic Intelligence

**Source/coverage:** Zenke, Poole & Ganguli, [ICML 2017 / arXiv v3](https://arxiv.org/abs/1703.04200v3), all ten PDF pages read, including appendices; references partly read. Derivations not independently verified; curves not visually audited.

**Mechanism:** Accumulate each parameter’s contribution to loss reduction along the learning trajectory. Use normalized importance to penalize later changes, consolidating estimates at task boundaries. Existing gradients supply the importance signal without an additional gradient pass.

**Evidence:** Split/permuted MNIST and split CIFAR classification retain earlier accuracy better than ordinary fine-tuning. Some CIFAR tests also improve new-task validation performance. The paper compares with published EWC results rather than a comprehensive matched reimplementation.

**Limits/contrary evidence:** Experiments concern classification, not interactive control. Split tasks use separate output heads and known task boundaries. Online importance accumulation therefore does not mean autonomous task recognition or boundary-free consolidation. Stochastic gradients bias importance estimates; damping and penalty strength need choices. The formal surrogate motivation covers two tasks, while longer sequences are supported empirically. Protecting earlier knowledge can reduce new-task performance.

**Mission implication — inference:** Consider learning-process memory as another retention mechanism, alongside explicit modules and experience replay. Test it on sequential game skills with delayed credit, changed mechanics and unknown boundaries before extrapolating classification results to an adaptive playing agent.
