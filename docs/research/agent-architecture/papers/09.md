# 09 A Standard Model of the Mind

[Laird, Lebiere and Rosenbloom, AI Magazine, 2017](https://doi.org/10.1609/aimag.v38i4.2744). Coverage: full 19-page author copy linked by the symposium organizers; main text, tables and references extracted. The publisher layout has 14 pages.

**Question and mechanism.** Can cognitive architectures share an abstract framework? The proposal combines procedural control, working memory, declarative memory, perception and motor systems. Modules operate concurrently, with a serial deliberate-action bottleneck and online learning.

**Evidence type.** Conceptual synthesis of ACT-R, Soar and Sigma, selected because the authors know them closely. Table 2 distinguishes theoretical agreement from implemented capability. This is neither a game benchmark nor evidence that the framework is uniquely necessary.

**Limits and alternatives.** The scope is humanlike minds, narrower than all competent artificial agents. Sigma realizes some distinct functions through shared underlying machinery. Motor control is underspecified; metacognition, emotion and other areas lack consensus. No extra planning module is required by their hypothesis.

**Mission implication — inference.** Use the framework as a comparison vocabulary, while testing alternatives beyond humanlike cognition.

**Test suggested.** Assess each implemented function separately; avoid scoring an architectural diagram as evidence of performance.
