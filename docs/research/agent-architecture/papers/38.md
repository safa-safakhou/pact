## 38 — AMP: Adversarial Motion Priors for Stylized Physics-Based Character Control

**Source/coverage:** Peng et al., 2021 paper; [arXiv v2, May 2022](https://arxiv.org/abs/2104.02180v2). Complete main text and appendices read; plots/motion footage not independently audited. Appendix D includes simultaneous walking/waving, beyond the main temporal-composition examples.

**Mechanism:** A discriminator rewards motion transitions resembling a reference dataset. Combine this style reward with task reward to train one feedback policy. Skill sequencing emerges without a separate motion planner or explicit clip selector. PD servos implement joint targets.

**Evidence:** Simulated locomotion, obstacle traversal, striking, dribbling, single-clip imitation, composition and ablations. Tracking methods often learn individual clips faster and more accurately. Gradient regularization and velocity features materially affect learning.

**Limits/contrary evidence:** Mode collapse can discard useful behaviors; front-flip learning can settle on shuffling. The motion prior is retrained per policy, with task-dependent generated data hindering transfer. Training uses 100–300 million samples per policy. State features, reference data and task rewards are supplied; this is motor control, not complete-game reasoning. Simultaneous composition retains artifacts.

**Mission implication — inference:** Explicit runtime hierarchy is one candidate, not a prerequisite for coordinated skills. Compare a unified policy with separate skill controllers under matched data and compute; evaluate behavior coverage, transfer, concurrent actions, and recovery separately from visual naturalness.
