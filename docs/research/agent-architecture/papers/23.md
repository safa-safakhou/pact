## 23 — Principles of Metareasoning

**Source/coverage:** Russell and Wefald, 1991, [journal record](https://doi.org/10.1016/0004-3702(91)90015-C). Read the [33-page author manuscript](https://citeseerx.ist.psu.edu/document?doi=d66a76715184959268bb3d88d6eb35596fb0f8f8&repid=rep1&type=pdf), complete main text through page 30. Extraction has font artifacts; equations and figure layouts were not independently audited; remaining references unread.

**Mechanism:** Treat computation as an action, valued by its expected effect on subsequent external choices and by delay. Estimate computational outcomes from experience. The analysis can guide designers or runtime control; it does not require an explicit optimizer before every action.

**Evidence:** Formal framework and summaries of search experiments, including Othello comparisons using the same evaluation function. Detailed experiments are delegated to cited papers.

**Limits/contrary evidence:** Optimal metareasoning itself costs computation and risks infinite regress. Practical greedy, single-step approximations miss computations that enable valuable later reasoning, creating a search-depth barrier. Authors explicitly expect reported gains to weaken against deeper search. Separating action quality from time cost can fail when different actions lose value at different rates. Long-term learning and compilation remain incompletely treated.

**Mission implication — inference:** Learn when further thinking changes outcomes, with cheap defaults. Test against fixed-budget search and learned reactive policies; include reasoning overhead, delayed-action losses, and sequences of reasoning whose benefits appear only later.
