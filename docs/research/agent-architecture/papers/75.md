## 75 — RT-H: Action Hierarchies Using Language

**Source/coverage:** Belkhale et al., [arXiv v2, June 2024](https://arxiv.org/abs/2403.01823v2). Read main text pp. 1–11 and appendix prose pp. 16–19; later figure panels, code and videos not audited.

**Mechanism:** One shared vision-language model predicts a short motion description, then actions conditioned on that description, task and image. Motion labels are automatically derived from robot actions. Asynchronous inference predicts the next motion while executing with the previous prediction.

**Evidence:** On eight selected tasks, success improves from 25% with flat RT-2 to 40%; training on language corrections raises RT-H to 63%. Action-cluster and language-label ablations help examine the intermediate representation.

**Limits/contrary evidence:** Uses a 55B model, internet pretraining and 100,000 demonstrations. Ten trials per task; novel-task correction examples are qualitative. Language-free clusters outperform on some precise tasks. Hierarchy introduces oscillation and repeated-command failures. Updating one query changes shared weights, so replay/co-training is needed to retain the other. Two sequential queries otherwise double inference time.

**Mission implication — inference:** Functional separation can improve learning and correction even with shared parameters. Intermediate representations need appropriate precision and timing. This addresses fine-grained action organization, rather than proving a solution for long-horizon strategy or fault-isolated execution.
