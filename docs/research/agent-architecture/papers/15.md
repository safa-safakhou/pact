# 15 Continuous Homeostatic Reinforcement Learning for Self-Regulated Autonomous Agents

[Laurençon et al., arXiv v1, September 2021](https://arxiv.org/abs/2109.06580). Coverage: all 17 pages. The text refers to an implementation appendix that is absent from this PDF.

**Mechanism.** Extend homeostatic learning to continuous time and state, including ongoing resource consumption and fatigue. Neural networks estimate dynamics and future deviation; an HJB-based rule selects discrete actions. Time is discretized for implementation.

**Evidence.** A stationary two-dimensional resource environment; learned value surfaces favor locations supplying currently needed resources. This is a proof of concept, with no comparative game benchmark, learning curves or general convergence result.

**Limits.** Section 3.1.2 assumes deterministic dynamics, fixed setpoints and immediately switchable actions. Resources are unlimited at fixed locations. The drive function is given beforehand. Complex goals and dimensional scaling remain unresolved. Missing appendix details constrain reproducibility.

**Mission implication — inference.** An agent’s needs can keep changing while it waits, but this does not establish strategic competence or robust control in stochastic games.

**Test suggested.** Vary resource locations, scarcity, observation errors and action duration; compare against simple threshold control and task-reward baselines.
