## 73 — Do As I Can, Not As I Say: Grounding Language in Robotic Affordances

**Source/coverage:** Ahn et al., [arXiv v2, August 2022](https://arxiv.org/abs/2204.01691v2). Read main text pp. 1–12 and implementation appendix pp. 19–24; remaining appendices, figures and code not audited.

**Mechanism:** Score known skills using language-model relevance multiplied by estimated feasibility, execute the best candidate, and repeat. Shared language-conditioned policies implement multiple skills; navigation and placement also use classical planning.

**Evidence:** Across 101 instructions, 84% planning/74% execution success in the mock kitchen and 81%/60% in the real kitchen. Feasibility grounding improves planning. Added drawer skills achieve perfect planning but only 33% execution over 21 queries.

**Limits/contrary evidence:** Object locations are assumed known. Feasibility scores require empirical calibration; placement is assigned feasibility one and termination 0.1. Skill training uses substantial robot demonstrations and simulation infrastructure. The planner appends selected skills, without reliably reporting their actual success. Greedy score multiplication is not a demonstrated guarantee of task completion. Long-horizon execution and negation remain weak.

**Mission implication — inference:** A cognitive component can choose among independently implemented skills through a common interface. The interface must communicate actual outcomes and calibrated capabilities. Better reasoning cannot manufacture missing mechanics, and successful plan selection is distinct from successful play.
