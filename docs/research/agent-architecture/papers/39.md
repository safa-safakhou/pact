## 39 — Universal Value Function Approximators

**Source/coverage:** Schaul et al., [ICML 2015 paper](https://proceedings.mlr.press/v37/schaul15.html), all nine main-paper pages read. Separate supplementary material not reviewed; plotted values not independently digitized.

**Mechanism:** One value model conditions on both state and goal, sharing structure across many goal-specific predictions. Separate state/goal embeddings can be learned via value-matrix factorization. Values can come from a collection of off-policy learners or direct bootstrapping.

**Evidence:** Gridworld generalization experiments and a Ms. Pacman demonstration using supplied pellet-location goals. The Atari result primarily shows value-map generalization; policy quality is described as preliminary and non-quantitative. This is not a complete-game benchmark.

**Limits/contrary evidence:** Useful generalization depends on goal representation and shared structure. Goal discovery is deliberately outside scope. Direct bootstrapping with function approximation can become unstable; restrictions and lower learning rates trade generality or speed for stability. Extrapolation is useful but far from optimal in the reported held-out-room test. Goals change rewards within shared dynamics, rather than defining unrelated games.

**Mission implication — inference:** Many specialized functions need not require separate model weights. Shared representations may support numerous skills or feasibility estimates. Compare isolated learners with goal-conditioned sharing; measure interference, held-out-goal control, calibration and changed dynamics, rather than prediction error alone.
