# 18 Behavior Trees in Robot Control Systems

[Ögren and Sprague, Annual Review, 2022](https://arxiv.org/abs/2203.13083). Coverage: all 25 pages, including formal definitions and proofs; results were read, not independently rederived.

**Mechanism.** Treat each subtree as a controller plus success/failure/running feedback. Operating regions describe when a controller takes effect. Composition can be analyzed through invariant sets and progress between regions.

**Evidence.** Theoretical convergence conditions and worked manipulation examples, with prior applications reviewed. Control barrier functions provide one method for enforcing compatible invariants.

**Limits.** Convergence requires well-defined dynamics, invariant conditions and bounded time to leave operating regions. “Optimal modularity” concerns a particular structural complexity measure, not optimal play. Incompatible objectives may force lower-priority goals to be dropped. Repeated fallback switching can prevent progress. Large policies can still grow unwieldy.

**Mission implication — inference.** A reusable skill needs applicability, completion, failure and preservation conditions. Common return values alone do not establish correct composition. Robust execution and strategic value require separate evidence.

**Test suggested.** Deliberately compose conflicting skills and interrupted fallbacks; check preserved conditions, eventual progress and recovery rather than only successful nominal runs.
