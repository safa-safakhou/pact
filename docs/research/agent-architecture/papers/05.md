# 05 Decision Making in an Embedded Reasoning System

[Georgeff and Ingrand, IJCAI 1989](https://ijcai.org/proceedings/1989/156). Coverage: publisher-extracted full main text, sections 1–6; the seven-page original PDF was subsequently acquired. Figures and mathematical typography are not independently checked.

**Question and mechanism.** PRS combines beliefs, goals, procedural knowledge areas, persistent intentions, and an interpreter. Bounded default decisions operate when richer metalevel procedures are unavailable. Deliberation itself remains interruptible. Intentions reduce repeated decision-making.

**Evidence.** The application connects multiple PRS instances to a real-time shuttle reaction-control simulator. The authors report detecting and recovering from sensor, leak, regulator, and jet malfunctions; detailed evaluation is referred to another report.

**Limits and contrary evidence.** Section 5 distinguishes noticing an event from completing an appropriate response. Reactivity depends on bounded primitive execution, event rates, and matching costs. Explicit response-decision bounds require additional procedures. Handwritten procedural knowledge supplies much of the competence.

**Mission implication — inference.** Weak planning can coexist with effective execution when the skill repertoire is strong. However, persistent commitments can preserve obsolete choices, and indiscriminate retries are dangerous for irreversible effects.

**Test suggested.** Weaken decision knowledge while holding procedures fixed; measure event detection, appropriate response, and goal achievement separately.
