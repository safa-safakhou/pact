## 67 — Counter-Strike Deathmatch with Large-Scale Behavioural Cloning

**Source/coverage:** Pearce and Zhu, [arXiv v2, December 2021](https://arxiv.org/abs/2104.04258v2). Read main text pp. 1–10 and appendices A/B/D/E/F; extended related-work section only partial. Figures, code and videos not audited.

**Mechanism:** Pretrain a visual recurrent policy on 95 hours of noisy human play, then fine-tune on clean expert demonstrations. Discretized mouse prediction and independent button outputs drive the game at 16 Hz. ImageNet initialization and engineered action inference support training.

**Evidence:** Deathmatch performance around casual-human/medium-bot level; substantially below the strong demonstrator. Clean fine-tuning improves results. Convolutional recurrence helps navigation, while an extra recurrent layer hurts.

**Limits/contrary evidence:** No competitive-mode economy, team strategy or long-horizon objective. Fixed weapon/team and chiefly one map; unseen-map kill rates drop sharply, with only partial recovery after demonstrations. Reported failures include forgotten enemies, missed indirect clues and unrecoverable positions. More varied weapon data reduces specialist performance. Humanlike movement and map coverage are separate from winning competence.

**Mission implication — inference:** Imitation offers a practical mechanical baseline when simulation cannot scale. Game integration, data quality, recovery coverage and action representation can dominate the choice of “brain.” Adding memory capacity alone does not ensure useful memory or broader cognition.
