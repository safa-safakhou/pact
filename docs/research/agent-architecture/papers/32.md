## 32 — Hierarchical Deep Reinforcement Learning: Integrating Temporal Abstraction and Intrinsic Motivation

**Source/coverage:** Kulkarni et al., [arXiv v2, May 2016](https://arxiv.org/abs/1604.06057v2), all 14 pages read. External animation and code not evaluated; plotted data not independently digitized.

**Mechanism:** A meta-controller selects goals using environmental return; a goal-conditioned controller selects primitive actions using intrinsic reward. Separate replay buffers and value functions operate at different temporal scales. A critic detects goal completion.

**Evidence:** A six-state stochastic task and Montezuma’s Revenge, demonstrating key collection and door opening. The Atari controller is pretrained for about 2.3 million steps before roughly two million additional joint-training steps shown in the result curve.

**Limits/contrary evidence:** Atari goals rely on a custom object detector and designed relational rewards. This is not automatic discovery of the full agent architecture from pixels. The authors explicitly identify missing object discovery, short-term memory, and interruption of ongoing options as barriers to solving the full game. Restricted first-room success does not establish complete-game competence. The small history-dependent task’s result is also not a general memory solution.

**Mission implication — inference:** Object-based goals can make exploration tractable when reliable entities are available. Account for detector engineering and pretraining when comparing methods. Test moving or missing objects, interrupted goals, multi-room dependencies, and reuse beyond supplied goal candidates.
