## 66 — Grandmaster Level in StarCraft II Using Multi-Agent Reinforcement Learning

**Source/coverage:** Vinyals et al., [Nature, 2019](https://doi.org/10.1038/s41586-019-1724-z). Publisher fetch failed; read the published paper from a [PDF mirror](https://gwern.net/doc/reinforcement-learning/model-free/alphastar/2019-vinyals.pdf): main text, Methods, extended captions and reporting summary. Supplementary ZIP, image-only tables and code not audited.

**Mechanism:** Recurrent policy combines unit attention, spatial processing and structured action generation. Human imitation initializes and continually regularizes learning. A league of main agents and exploiters develops strategies and exposes weaknesses.

**Evidence:** Grandmaster ratings across three races in anonymous online matches; extensive component ablations. Human data and opponent-diverse training materially improve performance. More permitted actions did not monotonically improve learning.

**Limits/contrary evidence:** Structured unit attributes replace visual interpretation; some information must be inferred or remembered by humans. Training uses opponent information only in value estimates, domain-designed strategy statistics, 971,000 human replays and twelve agents trained for 44 days on substantial TPU infrastructure. Online evaluation used four familiar maps; repeated targeted exploitation was not directly measured.

**Mission implication — inference:** A single deployed policy can combine mechanics and strategy without explicit hierarchical skills or online search. General-purpose algorithms still require substantial game interfaces, data and training design. Training organization and deployed agent architecture are different questions.
