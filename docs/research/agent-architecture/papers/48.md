## 48 — Successor Features for Transfer in Reinforcement Learning

**Source/coverage:** Barreto et al., [NIPS 2017 / arXiv v2, April 2018](https://arxiv.org/abs/1606.05312v2), main pp. 1–9 and experimental appendices pp. 15–24 read. Proof appendix not fully reviewed; curves not visually audited.

**Mechanism:** Separate predictions of future feature occurrences under each policy from reward weights. Revalue existing policies for a new reward and select actions through generalized policy improvement. Guarantees depend on bounded value-estimation error; similarity bounds require shared dynamics and suitable reward features.

**Evidence:** Sequential four-room tasks and simulated reaching, thirty runs. Policy reuse plus generalized improvement accelerates transfer; ablations distinguish improvement from simply retaining a factorized representation. Noisy/spurious-feature tests show gradual deterioration in the tested setting.

**Limits/contrary evidence:** This transfers across rewards within fixed dynamics. Navigation receives positions, object detection and task-change signals; reaching receives target identity and distance features for all targets. Policy storage grows without bounds in the navigation experiment. Overestimated values can dominate selection; feature changes invalidate stored predictions. Practical approximation errors are not automatically bounded by the theory.

**Mission implication — inference:** Skill arbitration should compare expected consequences under the current objective. Independent policies scored against different objectives cannot simply compete on raw scores. Test changed mechanics, unseen objectives, calibration and library growth before claiming general-game transfer.
