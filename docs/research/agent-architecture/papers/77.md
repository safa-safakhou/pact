## 77 — SayPlan: Grounding Large Language Models Using 3D Scene Graphs for Scalable Robot Task Planning

**Source/coverage:** Rana et al., [arXiv v2, September 2023](https://arxiv.org/abs/2307.06135v2). Read main text pp. 1–8 and appendices pp. 13–14, 46–48; remaining detailed examples, image panels and videos not audited.

**Mechanism:** An LLM expands/contracts a hierarchical scene graph to find relevant objects. It proposes high-level plans; Dijkstra supplies navigation paths. A symbolic simulator rejects invalid steps and returns feedback for up to five revisions. Real execution additionally uses perception, motion control and behavior-tree recovery.

**Evidence:** Ninety instructions test search and planning in two environments. Long-horizon plan executability reaches 86.6%, versus 13.3% for open-loop planning; correctness is separately assessed. Real-robot execution is demonstrated.

**Limits/contrary evidence:** Assumes a preconstructed graph, static object locations and encoded predicates/affordances. Executability in that abstraction does not establish physical success. GPT-3.5 performs poorly despite the same search framework. Negation, counting, distance reasoning and hallucinated nodes remain problematic. Larger graphs encounter token limits; more candidate rooms require more calls.

**Mission implication — inference:** Delegate exact graph operations and navigation to suitable algorithms, and distinguish valid actions from useful plans. Modular scaffolding does not ensure graceful degradation when the reasoning component becomes inadequate.
