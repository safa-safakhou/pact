## 33 — Diversity Is All You Need: Learning Skills Without a Reward Function (DIAYN)

**Source/coverage:** Eysenbach et al., [arXiv v6, October 2018](https://arxiv.org/abs/1802.06070v6), all 22 pages’ text read, including appendices; mathematical proofs and image-only skill panels not independently audited.

**Mechanism:** A skill-conditioned maximum-entropy policy learns behaviors whose visited states let a discriminator identify the skill. A fixed skill prior prevents training from concentrating on a few early winners. Downstream tasks select, combine, or fine-tune these skills.

**Evidence:** Simulated control, locomotion, hierarchical navigation/hurdles, and imitation experiments. Diverse behavior emerges without task reward during pretraining; downstream selection and training use task information.

**Limits/contrary evidence:** Diversity is not task competence: some skills fall over, and ant skills mostly curve rather than run straight. A supplied observation subset improves navigation. Fine-tuning plots omit pretraining under an explicit free/amortized-pretraining assumption. Quantitative imitation “experts” come from another random seed of the same algorithm; qualitative imitation fails on a handstand. Continuous function-approximation convergence is not established.

**Mission implication — inference:** Unsupervised exploration is a candidate source of mechanical skills, with an explicit diversity objective. Test downstream usefulness rather than discriminator accuracy alone, count pretraining costs, and evaluate required skills absent from the learned library.
