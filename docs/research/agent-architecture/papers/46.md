## 46 — Neural Episodic Control

**Source/coverage:** Pritzel et al., [arXiv v1, March 2017](https://arxiv.org/abs/1703.01988v1), main pp. 1–9 and appendix scores pp. 11–12 read; references partly read. Curves not independently digitized.

**Mechanism:** Learned visual embeddings address action-specific dictionaries of stored value estimates. Nearest-neighbor interpolation supplies action values. Experience rapidly updates dictionary values while slower gradient learning improves representations. Memories persist across episodes; capacity pressure evicts least-recently-used neighbors.

**Evidence:** Fifty-seven Atari games, learning curves averaged across five seeds. Early median performance substantially exceeds compared DQN/A3C variants; at ten million frames the median human-normalized score is 54.6%, versus 22.4% for prioritized replay.

**Limits/contrary evidence:** Prioritized replay overtakes NEC later; average and median rankings differ. Reward clipping differs between methods, affecting what behavior is rewarded. Storage reaches 500,000 entries per action; interaction efficiency is not equivalent to compute or memory efficiency. Stable embeddings and useful neighbors matter. This memory estimates values, rather than solving hidden-state tracking. Three-dimensional and real-world tasks remain future work.

**Mission implication — inference:** Rapid adaptation need not wait for full network retraining. Separate working memory, experience retrieval and slow learning as candidate functions, then test their actual contribution. Retrieval errors, representation drift and changing game rewards require direct evaluation.
