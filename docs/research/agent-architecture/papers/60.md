## 60 — Safe Reinforcement Learning via Shielding under Partial Observability

**Source/coverage:** Carr et al., [arXiv v2, August 2022](https://arxiv.org/abs/2204.00755v2). Read main text pp. 1–7 and technical appendix pp. 10–14; later plot collections not audited. PDF has 35 pages despite abstract metadata saying 21.

**Mechanism:** Track possible states from observation/action history using a partial transition model. A precomputed shield masks actions that leave a winning belief region. Exact transition probabilities and rewards are unnecessary; possible transitions must be adequately modeled.

**Evidence:** Six grid domains, five deep RL methods, sparse rewards and partial observation. Shields prevented specified failures and often improved learning beyond supplying state estimates alone.

**Limits/contrary evidence:** Eventual target arrival additionally requires fair action selection; no general arrival-time bound follows. Short episodes can favor risky unshielded agents because safe detours take longer. Some domains show little performance improvement. Smoothly withdrawing protection reduces violations but does not eliminate them: the reported aggregate still contains failures after learning. No general guarantee transfers to the unshielded policy.

**Mission implication — inference:** Observation history, estimated possibilities and action admissibility are distinct responsibilities. Knowledge supplied through these interfaces can help learning, but must be counted as prior engineering. Decide explicitly whether the objective permits occasional failure in exchange for speed.
