## 50 — Recurrent Independent Mechanisms

**Source/coverage:** Goyal et al., [arXiv v6, November 2020](https://arxiv.org/abs/1909.10893v6), main pp. 1–9 and appendix text/tables/captions pp. 14–35 read. References partly read; image-only masking demonstrations and curves not independently inspected.

**Mechanism:** Separate recurrent modules compete to receive input; only selected modules update. Attention permits communication with other modules, while inactive states persist. Modules learn their roles rather than receiving predefined task responsibilities.

**Evidence:** Sequence-length extrapolation, digit classification, object dynamics, distractors and Atari policy learning. Replacing an LSTM inside PPO improves many games. Ablations support selective input and communication; preliminary transfer improves nine of twelve target games, with three negative transfers.

**Limits/contrary evidence:** The independence assumption fits sparsely interacting factors; it is an inductive bias rather than a universal property. Too much or too little activation hurts. Shared decoders can fail despite useful modules. The implementation computes updates for all modules before masking, so sparse state updates do not establish proportional runtime savings. Module-removal evidence is qualitative video prediction, not a whole-game fault-tolerance test.

**Mission implication — inference:** This is direct evidence for testing internal modular computation, distinct from separate runtime services or skill hierarchies. Measure interference, changed factors, critical-module loss, latency and remaining task competence; modularity alone does not establish graceful degradation.
