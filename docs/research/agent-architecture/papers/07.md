# 07 The HEARSAY II Speech Understanding System

[Erman et al., ACM Computing Surveys, 1980](https://mas.cs.umass.edu/Documents/Erman_Hearsay80.pdf). Coverage: full main body and development appendix across a 41-page PDF; extracted figure labels reviewed, graphical layouts not exhaustively audited.

**Question and mechanism.** Independent knowledge sources generate and revise hypotheses on a shared blackboard. Events activate candidates; a heuristic scheduler allocates effort using expected contribution and credibility. Hypotheses can compete or reinforce one another.

**Evidence.** Section 3.1 reports nine-percent semantic sentence error on 23 unseen utterances from one speaker. Scheduling comparisons use different configurations and datasets and must not be pooled.

**Limits and contrary evidence.** Section 3.2 finds opportunism harmful at lower levels with unreliable ratings. In matched tests HARPY is faster and more accurate, although knowledge quality and debugging effort differ. Section 4.3 reports intolerable degradation when specialized internal processing is forced through the general blackboard.

**Mission implication — inference.** Shared state and flexible coordination can help uncertain inference, but uniform machinery everywhere can make an agent worse. Retain specialized internal representations and compiled alternatives.

**Test suggested.** Benchmark dynamic scheduling against fixed or compiled execution, varying uncertainty calibration and communication overhead.
