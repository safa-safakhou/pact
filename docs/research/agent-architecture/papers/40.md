## 40 — From Skills to Symbols

**Source/coverage:** Konidaris, Kaelbling & Lozano-Pérez, [JAIR 2018 paper](https://lis.csail.mit.edu/pubs/konidaris-jair18.pdf), main body pp. 1–69 of the 75-page PDF read. References omitted; proofs not independently verified, figure images not audited.

**Mechanism:** Supplied skills induce learned initiation conditions, outcome distributions and symbolic planning operators. Exact abstractions require particular subgoal and independence properties; practical classifiers, clustering and density estimates approximate these conditions. Planning uses the resulting compact representation.

**Evidence:** Playroom, a stochastic treasure game, and physical bottle manipulation. Treasure policies take under 0.2 seconds to compute; robot plans take milliseconds. The robot anticipates dependencies, such as opening containers before carrying the bottle.

**Limits/contrary evidence:** These are engineered domains with supplied controllers. Treasure observations are state features rather than pixels. Robot exploration actions were hand selected; tags support controllers, and memory assumes unobserved areas remain unchanged. Image alignment can take 45 seconds, despite fast planning. Compression produces false symbolic effects. Poor skill composition, complex preconditions and dependent factors can defeat compactness. Generalization across objects/locations remains future work.

**Mission implication — inference:** Learn or validate the interface between mechanical competence and cognitive planning. Measure complete sensing-to-action latency and actual execution success; a fast abstract planner alone does not establish a capable game agent.
