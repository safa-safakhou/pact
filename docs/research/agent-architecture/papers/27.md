## 27 — Hierarchical Reinforcement Learning with the MAXQ Value Function Decomposition

**Source/coverage:** Dietterich, [arXiv cs/9905014v1](https://arxiv.org/abs/cs/9905014v1), submitted 1999. Downloaded rendering has 64 pages and an anomalous 2024 title-page date. Complete main text and end figures read; proofs inspected, not independently verified; figures not all visually audited.

**Mechanism:** Programmer-defined subtasks, termination predicates, and pseudo-rewards produce a reusable subroutine hierarchy and additive value decomposition. Five sufficient abstraction conditions permit ignoring state. Learning targets recursive optimality; greedy execution can relax hierarchical commitments.

**Evidence:** Conditional convergence proofs and experiments on stochastic Taxi and two navigation domains, with hierarchy, abstraction, and execution variants.

**Limits/contrary evidence:** Recursive optimality can be worse than the best hierarchical policy. Poor termination goals create loops. Without useful abstraction, the representation can use more memory and learn more slowly than flat Q-learning. Some reported gains require carefully tuned exploration and initialization. Switching execution regimes exposes poorly learned states and temporarily hurts performance. Full observability and supplied hierarchy are substantial assumptions; the learning theorem is asymptotic.

**Mission implication — inference:** Modularity trades reusable local competence against access to global context. Evaluate hierarchy, abstraction, reward decomposition, and interruption separately. Measure whole-task success alongside skill success; explicitly test misleading subgoals and failures hidden by abstraction.
