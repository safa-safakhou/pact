## 51 — Progressive Neural Networks

**Source/coverage:** Rusu et al., [arXiv v4, October 2022](https://arxiv.org/abs/1606.04671v4), originally 2016, main pp. 1–8 and supplementary pp. 10–14 read. References partly read; sensitivity calculations/curves not independently audited.

**Mechanism:** Freeze each learned network column, add a new trainable column for each task, and learn lateral connections that reuse earlier features. Existing task computations remain intact.

**Evidence:** Pong variants, unrelated Atari games and 3D mazes show transfer beyond simple output-layer reuse. Sensitivity analyses identify reused perceptual and control features. Atari transfer is positive in eight of twelve targets, with two negative cases.

**Limits/contrary evidence:** Results average the best three of twenty-five jobs after hyperparameter sampling. Transfer can hurt when inherited features trap learning or exploration. Network capacity grows; the appendix identifies quadratic parameter growth in the basic arrangement. Compression is suggested from sensitivity evidence, not demonstrated as a complete solution. Inference requires the task label. Preserving old functions protects against training interference, not changes to the old environment.

**Mission implication — inference:** Frozen capabilities plus new capacity offer a concrete retention strategy. Compare it with shared/adaptive networks under fixed memory, test automatic task selection, and measure both retained skill and adaptation. Retaining every module is a resource tradeoff, not a free route to lifelong competence.
