## 76 — Hi Robot: Open-Ended Instruction Following with Hierarchical Vision-Language-Action Models

**Source/coverage:** Shi et al., [arXiv v2, July 2025](https://arxiv.org/abs/2502.19417v2). Read main text pp. 1–9 and appendix pp. 13–15; references, image panels and videos not fully audited.

**Mechanism:** A high-level vision-language model issues short commands to a continuous-action policy. The high-level model runs every second and immediately upon user feedback; the controller executes action chunks. Both use pretrained models, with separate training for their roles and synthetic instruction/interruption data.

**Evidence:** Physical experiments cover table clearing, sandwich making and grocery handling. Hierarchy and synthetic-data ablations improve instruction accuracy and task progress. These metrics measure command consistency and partial completion, rather than whole-episode success.

**Limits/contrary evidence:** High-level models are trained separately per task domain. Missing memory causes history-related failures; the controller can ignore commands, and unfamiliar dropped objects produce accumulating errors. Models lack explicit knowledge of each other’s capabilities. Reported 50 Hz control uses chunks: fresh action inference is roughly 10 Hz. Training-time estimates exclude foundation-model pretraining and substantial demonstration work.

**Mission implication — inference:** Periodic decisions plus event-triggered revision are a concrete coordination mechanism. Separate roles help here, but this does not establish cross-game generality or prove that weakening the reasoning model preserves competent execution.
