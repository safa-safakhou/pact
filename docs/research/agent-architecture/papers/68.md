## 68 — Hierarchical Imitation and Reinforcement Learning

**Source/coverage:** Le et al., [arXiv v2, June 2018 / ICML](https://arxiv.org/abs/1803.00590v2). Read main text and all appendix prose/tables in 14-page PDF; proofs read, not rederived; plots/code not audited.

**Mechanism:** Expert feedback selects useful subgoals and limits low-level teaching or RL updates to relevant trajectories. Inspection requests identify which skill failed before demanding costly action labels. The framework mixes imitation and reinforcement learning at different levels.

**Evidence:** Generated maze navigation improves success and label efficiency. Montezuma’s first room learns much faster than the adapted hierarchical-DQN baseline over 100 runs.

**Limits/contrary evidence:** Experts supply the hierarchy, intrinsic rewards and termination detectors in the hybrid experiments. Almost half the Montezuma runs fail to finish learning the fourth skill within four million frames. Replay starts only after positive reward; mastered skills stop training at 90% recent success. Separate skill networks reduce observed forgetting, increasing storage. Cost bounds assume finite realizable policy classes and a particular feedback-cost model.

**Mission implication — inference:** Mechanical skills and higher-level guidance can use different learning channels. The benefit is targeted supervision rather than decomposition alone. Evaluate weak skill completion and detector errors explicitly: a correct high-level sequence still fails when one required skill is unreliable.
