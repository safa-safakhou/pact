## 79 — Voyager: An Open-Ended Embodied Agent with Large Language Models

**Source/coverage:** Wang et al., [arXiv v2, October 2023](https://arxiv.org/abs/2305.16291v2). Read main text pp. 1–11 and appendices pp. 19–20, 24–25, 37–42; remaining prompts, code and videos not audited.

**Mechanism:** A curriculum proposes tasks; a code generator composes retrieved procedures and control APIs. Execution feedback, interpreter errors and a model-based success critic drive up to four attempts. Successful programs enter a searchable skill library.

**Evidence:** Three Minecraft runs show improved exploration over adapted language-agent baselines. Ablations support the curriculum, library and feedback. Stored skills accelerate four new tasks in fresh worlds. Initial diamond-tool attainment occurs in only one of three runs.

**Limits/contrary evidence:** Structured observations and Mineflayer navigation/combat/mining APIs supply much of the mechanical competence. Death preserves inventory and triggers resurrection. Prompting iterations measure efficiency rather than elapsed time or total compute. Replacing the code generator with GPT-3.5 sharply reduces progress, while other major components still use GPT-4. Critics misjudge outcomes; hallucinated tasks and APIs persist.

**Mission implication — inference:** Persistent executable skills and outcome checks are useful candidates for cognitive progression. This demonstrates same-game transfer with strong interfaces, not visual motor learning or competence across unrelated games.
