## 53 — Overcoming Catastrophic Forgetting (EWC)

**Source/coverage:** Kirkpatrick et al., [arXiv v2, January 2017](https://arxiv.org/abs/1612.00796v2), main pp. 1–7 and appendices pp. 10–13 read. References partly read; mathematical approximations and plotted curves not independently audited.

**Mechanism:** Penalize changes to weights estimated important for earlier tasks, using a diagonal Fisher approximation and stored parameter anchors. Unlike freezing whole modules, protection varies by parameter. The Atari system also infers task context and uses task-specific gains/biases.

**Evidence:** Permuted-digit classification and sequential Atari experiments show less forgetting than unprotected learning. Atari evaluation samples ten-game sets from nineteen games already tractable for standalone DQN, with multiple task sets and seeds.

**Limits/contrary evidence:** Performance remains below separate specialist networks. Perturbations damage supposedly unimportant directions, exposing approximation error. Protection starts only after substantial game experience. Atari additionally uses per-task replay buffers, context models and task-specific parameters, so fixed shared-network capacity does not imply fixed total resources. The experiment is not evidence of universal forgetting prevention or unrestricted skill accumulation.

**Mission implication — inference:** A shared agent can protect prior competence without isolating every skill into a separate model. Compare regularization, freezing and replay while measuring old-task retention, new-task learning and context errors. Capacity and uncertainty estimates determine the tradeoff.
