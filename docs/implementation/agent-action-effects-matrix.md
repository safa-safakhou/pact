# Agent action effects matrix

Source candidate, 21 October 2026. Default-off protocol; no installation or behavioral qualification.

All eight supported actions use the existing authenticated principal, game admission, native handler, authority/lease checks, SERIALIZABLE retry, receipt and outbox transaction. Quotes run in a read-only transaction. They bind the exact native command digest; guarded command hashing additionally includes the original guard. Receipt lookup precedes current-world admission, preserving retries while paused.

The owner revision covers committed clock/rules/tick/status; ranked ownership/account state; ledger founding-expiry/balances; buildings/builders/live instructions/training/troops/upkeep; mandate/version/floors; authority ledgers, rolling spends, commitments/assets; rolling action events; related offers/signatures/active contracts; social contacts/blocks/mutes/delegation/pending introductions; current leases/run-message budget; moderation restrictions. Dependencies are read in the same transaction. A referenced counterpart adds an opaque digest of its equivalent dependencies and pending byte queues; raw private counterpart facts never leave the server. These broader revisions conservatively reject some unrelated changes. A dependency query over10,000 rows fails closed instead of truncating coverage. No outlook hash is reused.

At commit, the world clock is already locked by normal admission. The owner kingdom is locked before dependency validation; SERIALIZABLE predicate reads cover new rows/ranges and authority/lease writers. Retries recompute against the same original guard. The unchanged domain handler acquires its existing ranked-pair, offer, resource, authority, lease and queue locks and validates current service/deadline conditions. Quote validity is30 UTC seconds; changing wall time is not a source revision. Communication credit arithmetic uses the original quoted instant, while the actual handler checks the current instant. A later replenishment is never a silent rebase.

Claims describe complete owner-local coordination effects; the guard binds counterpart prerequisites without disclosing counterpart capacity. Peer bonds are debited only by the existing paired activation transaction. Incoming flow, acceptance, admission and receipts never establish later delivery. Cancellation, military, garrison and every unlisted action are unsupported. Missing dependencies, malformed/fabricated effects and stale guards fail before mutation. Owner reserve constraints can tighten ordinary resource floors; they never widen authority.
