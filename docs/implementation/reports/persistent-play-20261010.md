# PACT-154 — Owner consent and bounded future turns

Implemented under the founder's PACT-146–165 assignment. The first supported route is the existing PACT API inference worker, with a separate human-only, exact/revocable enrollment and lifetime allocation budget. It admits bounded existing runs under the shared kingdom lease; no additional gameplay authority or provider credential access is granted to a model. Initial mission and durable non-run inbox sequences queue/coalesce work; only the inference worker can admit model work, never notifications/rules. Waiting/failure/lease loss requires an owner decision. The deadline, full slice reservations and sequence survive restart without replenishment.
