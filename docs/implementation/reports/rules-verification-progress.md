# PACT-051 rules verification — progress record

Ticket: [PACT-051 / MNI-115](https://linear.app/mnim/issue/MNI-115/pact-051-run-transaction-replay-and-adversarial-rules-tests) — in progress. Implementation revisions: `7eccf06`, `804198c`, and `b38c5f5`. Verification: 24 Sep 2026, Node 24, PostgreSQL 17 with PostgreSQL client 18.4.

The new seeded integration fixture runs 120 deterministic ledger operations with pre-commit failure injection, idempotent replay, an independent balance model, and journal reconciliation. The restore rehearsal dumps and restores an isolated synthetic schema and verifies recovered stock, troop placement, committed receipt, and deduplicated outbox delivery. Both checks passed locally. `npm run build`, `npm run typecheck`, `npm test` (104), and `npm run test:integration` (129) passed; lint passed after formatting. See [verification instructions](../../architecture/rules-verification.md).

The next adversarial fixture submitted two account signatures and a duplicate same-ID retry concurrently through the shared world-admitted dispatcher. It first exposed a unique-key race in the successful-action ledger. The dispatcher now rereads a durable receipt after that specific unique-violation class and returns it only for the same authenticated account and canonical payload; otherwise it rethrows. The fixture verifies one contract, two signatures, two receipts, and a conflicting-payload rejection. This is a bounded R04/R06 result, not proof of every authority race or durable transition.

After this increment, local Node 24 `npm run build --workspace @pact/application`, `npm run typecheck`, `npm test` (107), `npm run test:integration` (135 on PostgreSQL 17), and `npm run lint` passed. The initially failing race is retained as a regression fixture. No hosted CI or full VPS recovery was run.

A later R04 fixture holds the account row while revoking an agent's transfer mandate, submits the agent command concurrently, and verifies that the pending command observes the new mandate version. It produces no transfer, stock debit, or committed receipt. The fixture uses the existing MCP write lease and shared world-admitted dispatcher rather than bypassing authorization. Local Node 24 typecheck, full lint, and 138 PostgreSQL 17 integration tests passed after this addition. This proves the revocation-first interleaving, not every possible command/revocation race. The [R04 matrix](../../architecture/rules-verification.md#r01r06-evidence-matrix-incomplete) was updated; PACT-051 remains In Progress.

A later R06 fixture injects an exception immediately after a fake-provider game command commits and before `RunService` reconciles the provider step. The run fails conservatively with an ambiguous-crash marker and releases its lease; the committed command receipt and message remain. Replaying that same run/request/call command ID returns the original receipt with one message, and a second model step does not begin. Node 24 `npm run test:integration` passed all 140 PostgreSQL 17 tests, and lint passed after this increment. This is deterministic post-commit failure injection, not a killed worker process or complete durable-tool-result recovery. The wider fault matrix and full VPS base/WAL restore are still open.

PACT-051 remains open: the [R01–R06 matrix](../../architecture/rules-verification.md#r01r06-evidence-matrix-incomplete) maps current fixtures and gaps, but generated cross-module scenarios and fault injection around every durable command/tick transition have not been completed. This rehearsal is not a full VPS base/WAL backup restore, hosted CI run, or pilot observation.
