# Precise credential recovery source acceptance

AR-P07 / PACT-177 and AR-F07, 15 October 2026. Source and fake/isolated verification only.

Fleet distinguishes locally confirmed pre-HTTP connection refusal, explicit OAuth rejection, ambiguous transport/502/lost acknowledgement and a valid rotation response. Only a local fetch TypeError with ECONNREFUSED (or an aggregate containing exclusively such refusals) permits one immediate retry. A gateway status, error prose, reset, timeout or mixed aggregate never supplies this proof. If both attempts are confirmed not processed, old credentials remain ready and AUTH_TEMPORARY hands off to the existing original scheduled turn without model allocation. No retry is bought by clearing counters or pending commands. An explicit INVALID_GRANT is preserved as rejection, not proof of every possible server-side cause; reconnect is required.

Refresh and OAuth callbacks share an account advisory lock. Refresh writes compare original ciphertext, account binding and exact fence; newer grants cannot be overwritten. A pause/fence change stops retries. Confirmed unrotated credentials can remain ready behind the pause; an acknowledged rotation that cannot be saved safely is quarantined for same-account reconnect. OAuth nonces bind the captured credential fence, operator and expiry; callbacks check the same source generation/ciphertext at save and advance the fence. An older/missing-generation nonce is refused before exchange and retained as uncertain history. Busy callbacks do not consume a nonce or start an exchange. Same-account synthetic reconnect retains entry key, identity and authority. No model receives tokens.

PACT adds an internal owner-bound readRefreshEvidence diagnostic port, not a public route/tool or credential-validity oracle. It returns only version, current unused/rotated/revoked/expired/unknown state, observation time and an explicit safeToRetry:false. Foreign owner/client and nonexistent token are indistinguishable unknown. It reveals no token/hash/grant secret, changes no token and does not treat current unused state as proof that an earlier attempt never executed. Existing rotation, resource/scope binding, reuse-family revocation and canonical receipt semantics remain authoritative.
