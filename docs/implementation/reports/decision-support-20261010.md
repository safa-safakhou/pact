# PACT-152 — Exact decision facts and reads before action

10 October 2026, authorized dependency-ready follow-up to the released communication workspace. Implemented shared construction affordability/prerequisite/cost facts, training quote/unlock helpers used by both the troop engine and decision reader, and one shared supply exposure calculation for signature reservation and observed proposals. Conditional forecasts/upkeep/charges use the existing authorized owner projection. Known operation definitions and completion effects remain separate from unknown future combat and peer choices.

The optional, unranked menu includes wait/read, concrete builder/training examples and version-bound proposal withdrawal. It is not a whitelist or policy ranking. Candidate resolution reads current state and returns a blueprint only; changed balance versions within the same tick invalidate old candidate IDs. V2 withdrawal optionally binds the observed offer version; stale withdrawal fails before releasing signatures or modifying the offer. Legacy v1 schemas, exact submitted commands and unversioned historical pending withdrawals remain compatible.

HTTP, external MCP and in-app provider adapters share `DecisionSupportReader`, deriving identity from the session/run/scoped grant. Query identity overrides and write-only tokens are rejected; a read never grants permission, writes a receipt, acknowledges text or starts inference. Proposal conveniences page twelve from the latest observed set; when fifty were observed, deeper-history uncertainty is explicit. Large menus remain below the run result byte limit.

The local full-game controller now reads before acting. A plan asking for more facts commits none of its accompanying actions; read results persist before the subsequent eligible decision. Failed reads/stop cannot fall through to a command. This preserves one model call per turn and PACT-143 pacing. No native checkpoint/task, population, budget, model choice or experimental setting was changed or restarted.
