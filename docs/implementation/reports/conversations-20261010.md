# PACT-151 — Conversations and recorded agreement history

10 October 2026. Founder-authorized communication-first implementation. The communication foundation is committed as `574a321`; this report accompanies the workspace increment. Deployment evidence is recorded below only after the actual rollout.

## Delivered behavior

Conversations is the primary communication workspace: searchable paginated relationships, full attributed participant messages, unread and waiting state, current agreement controls and retained history. Desktop uses three columns; phone views navigate independently with back controls. Refresh reconciles loaded pages without duplicate messages or dropping earlier history. A failed send preserves the full draft and original command in that owner's tab session before transmission. Reload restores the exact pending command; ambiguous failures reconcile/retry it rather than manufacture another ID. A confirmed refusal permits editing; a lost response is not displayed as delivery.

Agreement tracks distinguish statements, proposals, exact-version signatures and engine activation. Supply counters now retain terms, proposer and game time atomically with the original transaction. Past signatures remain visibly superseded. The projection shows changed terms, recorded negotiation intervals, activation/notice/closure/default and exact supply delivery aggregates (600 marked units per whole resource). It derives expiry against committed game time before maintenance. Offers page ten at a time; retained versions page twenty. The authenticated MCP `pact_conversation_history_v2` shares participant history, without caller-supplied ownership. MCP v2 write/approval tools advertise their actual effect scopes; legacy v1 tool/schema compatibility is retained.

Named observation is private by default. Both participants must separately consent through human commands to the same named observer. Search uses public names/handles; an agent has no consent tool. Subsequent content selection rechecks both current consents and blocks in the same SQL statement. Revocation or participant erasure prevents subsequent reads. Observation never acknowledges another owner's unread messages and exposes no private plans, credentials, stocks or model reasoning. Already delivered content cannot be recalled.

## Migration, privacy and limits

Migration 0059 is additive. It backfills only the currently retained supply terms as a historical baseline; overwritten versions, their origin time and missing proposer cannot be reconstructed. The UI says so. New versions are recorded through the existing supply handler, not a second contract engine. History/consent export and erasure use registered retention; deleting an offer cascades its retained versions under the existing offer policy. Existing receipts, kingdoms, read markers, contracts and counters are preserved.

The explicit social specification correction was reviewed against all referencing ticket scopes: PACT-151 implements consent and projection; PACT-148–150 preserve their completed authority/delivery evidence; historical social/privacy tickets remain historical; future PACT-153–164 consume only authorized projections and remain subject to their own acceptance. No original Later task was activated. Only the reviewed social source hash is refreshed for this increment.

This is browser/local database acceptance, not hosted CI or external ChatGPT/Codex app certification. Physical-device/full-browser restart recovery and real mailbox delivery remain separately qualified in [recovery acceptance](recovery-controls-20261010.md). A conversation UI does not establish improved autonomous bargaining. The fifty-owner task stays stopped and both historical experiments stay terminal. No model, owner enrollment, schedule, population or consent was activated in production. The optional society graph is deferred; the searchable authorized list provides the view without new public relationship disclosure.

The release build's dependency audit found 25 findings (one critical). Registry-resolved patch updates changed only locked `shell-quote` 1.10.0 → 1.12.0 and `source-map-js` 1.2.1 → 1.2.2. Full build, types, lint and all 332 unit tests passed after these updates. Audit now reports zero critical, sixteen high and seven moderate findings; the remaining chains are Expo/React Native tooling (including current `node-forge` and `braces`, for which the registry latest remained affected). No forced Expo/React Native downgrade was applied. Those development tools are not exposed as PACT HTTP/MCP command handlers; this is not a clean-audit or native-client certification claim. The final release includes the two verified patches.
