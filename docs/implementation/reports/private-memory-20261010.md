# PACT-153 — Private strategy, relationships and provenance

10 October 2026. Implemented under the founder's PACT-146–165 assignment, following the committed decision-support increment. Private note types cover assessments, strategy, goals, milestones and questions, with relationship/topic retrieval, immutable versioned corrections and authorized source pointers. They are separate from game receipts, the owner's objective and authority. Migration `0060_private_memory.sql` creates empty account-owned tables; it grants no access, starts no models and copies no transcripts or hidden reasoning.

The human API, scoped MCP read/write/source tools and in-app read/write tools use the same service. In-app writes recheck the active run lease in the transaction; a fake provider returning after its run was stopped cannot save a note. Source metadata never acknowledges messages or grants access: original participant readers own terms, full messages, delivery/defaults and military facts. Missing sources degrade to unavailable. Export/forgetting include only owned notes and clear erased counterpart references. Superseded/deleted content follows the thirty-real-day retention period while current strategy persists and exact replay hashes remain.
