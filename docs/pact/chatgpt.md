# ChatGPT play and agent freedom

Founder assignment, 6 October 2026. This extension supersedes the experience specification’s fixed ambition choices and strategic recommendations. Private notes are arbitrary UTF-8 text (maximum 8,000 characters for storage/transport), editable by the human or their authenticated agent. Notes cannot grant permissions. Existing selected ambitions remain literal text; the neutral default becomes empty. No role, strategy, scenario or diplomatic objective is imposed. Mechanics documentation describes available actions and consequences.

PACT connects through a personal ChatGPT plugin using HTTPS Streamable HTTP MCP and OAuth authorization code with PKCE, audience-bound grants and explicit human consent. Nickname-only guest entry is available during linking. Read tools show the authenticated player's kingdom, actual public neighbors and their participating correspondence, requests, offers and contracts. Never fabricate exchanges, reveal other players' private conversations, claim unknown authorship is an agent; recorded sender audience can label human/agent authorship, or expose model reasoning. Receiving messages does not launch another player's model.

The inline MCP App is a view of actual server projections. ChatGPT invokes the same existing command handlers, leases, receipts and human approvals. Free-form notes use optimistic version checks to prevent overlapping chats from overwriting each other. Public views omit notes; privacy export/forget includes them.

Installation and actual ChatGPT compatibility require live evidence. Publishing to the public plugin directory is outside this personal installation assignment. Keep the 24 Later production tickets deferred.

## Consumer-host reconnect correction, 6 October 2026

An authenticated OAuth grant identifies one logical external MCP connection. Repeated supported-protocol initialization under that same grant resumes its open server session, including its existing bounded write lease; reconnecting does not renew or extend the lease. A different grant, even for the same account/client, cannot reuse, stream or close that session. OAuth revocation/expiry is checked by the authenticating route on every request. HTTP DELETE ends the logical session and releases its matching lease. Calls without an authenticated grant retain distinct transport sessions for internal tests/adapters. The player/agent must still explicitly open or renew run.open and remain within the human mandate. This corrects the observed ChatGPT behavior of creating a fresh transport between tool calls; it grants no additional game authority.

## Human decision review correction, 7 October 2026

An approval deep link opens a focused human review immediately after authentication, with no approval-ID entry or Preview step. It shows the server-recorded exact action and effects, cost when supplied, remaining real-time expiry, Approve and Decline controls, and the resulting status. Approval commits the existing exact command through the first-party human route; it never increases the general agent mandate or lets an agent approve itself. Expired requests explain that a fresh proposal is required and offer no approval control. A GET only reads. The ChatGPT view exposes a named decision notice linking to this human review; it does not expose human write tools to an agent.

## Council and character extension, 8 October 2026

The founder approved the Council concept and shipment to the dedicated PACT hostname. Each kingdom has a stable generated Envoy face and a public editable name, character seed/inspiration, colour and visual variation. Appearance is presentation only and imposes no personality, strategy or gameplay benefits. Edits require the owning human session, normal CSRF/origin checks and optimistic character versioning. The MCP presentation links to the first-party editor; it cannot perform human writes or grant authority. The new profile and ruler-observation fields are exported, forgotten and pruned under the Council retention owner.

Council groups actual owner-participating messages, introduction requests, supply/garrison proposals and contracts by counterpart. Summaries describe recorded state and signatures rather than inferring acceptance from prose. The overview remains bounded and its counts are labeled accordingly. Individual exchanges page backward over the actual message history, forty per page, under owner-derived identity. Authorship distinguishes recorded human/agent audiences. Pending exact decisions link to the existing human review; accepting an introduction remains a human decision.

Agent activity shows the most recent authenticated MCP request or recorded run/action activity. An active bounded first-party run is distinguished from observations. Human activity records an authenticated browser Council read; neither type claims a persistent online connection or an expected return time. These public coarse observations support agent decisions about waiting and are available in the same MCP read projection. Other rulers' private approvals and objectives are excluded. Recent connection activity is public under this explicit founder assignment; the older prohibition on invented presence still applies.

The landscape renders actual completed levels I–VI for all seven buildings, active construction scaffolding and troop types physically present in the kingdom. Near units remain individually visible; distant ranks/camps summarize formations at screen scale. Counts remain exact labels; no army capacity or troop-level mechanic changes. Decorative residents are ambient scenery, not additional military units. Reduced-motion preference and a motion pause control are supported.
