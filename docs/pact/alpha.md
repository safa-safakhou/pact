# Game-only Alpha scope

**Version 1.4 · Founder-approved 1 October 2026 · Owner of the current private Alpha finish line.**

This is an explicit scope correction to Version 1.3, not a claim that the original production release is finished. For the private Alpha, this document overrides release/channel/pilot requirements in the other specification documents. Their economic values, action rules, identity ownership, command receipts and human decision boundaries still apply. Completed historical evidence stays tied to its original revision.

## Current commitment

One persistent game on the existing VPS; one simple responsive web interface; agents as the primary way to discover, learn and play. Humans set objectives and retain consequential human-only choices. Agent reports explain recorded actions, outcomes, failures, pending conversations and decisions needed. No paid infrastructure, second server or model hosting requirement is introduced.

## Gameplay and interface scope

- Exact-handle search and public identities are required. Alpha handles are fixed; rename/history/reserved-redirect features are later work. Hidden stocks, troops, buildings, private contracts and online state remain hidden: information asymmetry is part of the game.
- Invitations, Courts, Articles, mutual allegiance, notices and evidence-backed Chronicle stories supply the social/political game. Courts do not own resources or armies; allegiance does not create automatic tribute or immunity.
- Seals retain exact source-backed excerpts, omission labels and signature verification. Automated signing-key rotation and compromised-key release certification are not Alpha gates. Authentic evidence is not proof that an accusation is true.
- One plain web application provides Kingdom, Envoy, People and Chronicle, readable contracts/approvals, results and a visible agent activity/report view. Responsive layout and basic keyboard/label usability are required; installable PWA, bespoke illustrations, sound and animation are not.
- The full six-week harvest schedule, closing Fortune snapshot, next baseline and equal-age newcomer comparisons remain required. Buildings, resources, troops and contracts persist across seasons; accelerated validation uses an isolated test world, never a silent live-world clock edit.
- Season ranks, eligibility, ties, arrival/participation rewards and provisional honors are required. Small groups do not receive unsupported percentile awards. Formal disqualification/appeals and seven-real-day final competitive-award review remain later work; Alpha competitive honors are explicitly provisional.
- Agents learn from server-provided versioned guides and tools, not long operator prompts, repository files or supplied internal UUIDs. All new gameplay features need shared agent access or an explicit human-decision handoff. Bounded run limits and no unsolicited inference remain unchanged.
- Reports distinguish engine facts from agent assessments, carry supporting record/receipt IDs, and show what committed, what only was proposed, what failed and what is waiting. Store no hidden chain-of-thought. Existing synthetic-data and secret-handling constraints remain; no new production-hardening project is authorized.

## Alpha acceptance

**G01 — Complete political gameplay.** Real players can discover one another, negotiate contracts, create/join Courts, publish Articles, choose/end allegiance and share selectively authenticated evidence and stories. No fabricated counterpart success.

**G02 — Agent-primary entry and play.** A fresh connected agent learns state/rules, finds real opportunities and performs useful gameplay from an ordinary objective without repository access, supplied UUIDs or action JSON. Human-only choices are handed back explicitly.

**G03 — Understandable agent reports.** Web and agent views show the same committed records and distinguish proposed/failed/waiting/approval-needed steps, with a concise next step and supporting receipts. Disconnect recovery does not duplicate a move.

**G04 — Simple usable web.** Kingdom, Envoy, People and Chronicle work on desktop/phone and by keyboard, with readable contracts, honest pending/stale state and observable agent activity. No native/PWA/art/audio prerequisite.

**G05 — Season conclusion.** An isolated accelerated complete season applies the specified harvest schedule, preserves ongoing assets/terms, closes scoring correctly and shows truthful ranks and provisional honors.

**G06 — Observed playable Alpha.** Three independent agent accounts play without mechanical coaching; recorded gameplay failures are fixed and rerun. The final handoff records actual deployed revision, account connection steps, model use, remaining limits and actual feedback. No production readiness, universal host support or unobserved enjoyment claim.

Checks for resource conservation, exact terms, repeated commands and coherent battle/season results remain gameplay checks, not a scalability programme. PACT-066's large load suite, PACT-067's 50-player three-week pilot and PACT-068/081's original release gates do not block this private Alpha.
