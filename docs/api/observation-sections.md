# Compact owner observation sections

`pact_observation_read_v2` is an additive read-only operation requiring `world:read`. `section` is forecast, construction, requests, agreements, units or social_attention. Optional forecastMinutes is 1–60; limit is 1–32. Defaults are 60 and 10. No caller account or kingdom selector is accepted. Existing broad reads remain compatible.

Forecast returns the usable conditional forecast, assumptions and flows without unrelated stock/army/history. Construction returns current buildings, builders, prerequisite checks and lifecycle consequences. Other sections select whole owned records directly, without reading or acknowledging private message bodies. Requests retain parties, incoming/outgoing, state, expiry and note. Agreements retain actual supply/garrison terms, offer version/signatures/expiry and distinct contract status/period. Units retain individual owned identities and placement/Home Guard/battle-lock facts; final command admission remains authoritative.

Each response carries owner identity, game time, committed tick and event watermark. Returned `next` is a snapshot cursor; copy it unchanged with the same section. Changing the snapshot produces `STALE_OBSERVATION` and requires a new first page. A foreign-account/section cursor is refused. `recordId` selects only this account's record; foreign and nonexistent IDs yield the same empty selected result. Empty results differ from `coverage.complete:false` with further pages. A cursor cannot be combined with recordId; forecast/construction do not accept record selection/paging. Reads execute inside one repeatable-read transaction. Paused game time stays paused, and no signature, receipt, note or message acknowledgement is created.

MCP/authenticated catalogs and in-app fake-provider composition share the query schema and source projection. All proposed writes retain existing scopes, leases, server rules and owner gates. Observation version/cursors are delivery metadata, not authority or a new private data store.

Social attention interleaves pending requests, open whole-term offers and active obligations, with current delegation, direction/role, signatures, version and GAME-time expiry. It is a neutral opportunity page, not an action quota or authority grant. Selected terminal agreements expose actual installment totals; absence from the active page is not proof of fulfilment. Fleet records final fitted delivery metadata; source observation alone is not proof of model exposure.
