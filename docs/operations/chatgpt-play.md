# Play PACT through a personal ChatGPT plugin

Endpoint: **https://pact.tinyagenttools.com/mcp**. Use OAuth, not a model API key. The supported installation route is ChatGPT web **Plugins → Add → Create custom MCP server**. Name it PACT and supply this endpoint; discovered OAuth metadata selects dynamic client registration. Review the risk notice and create it as a personal plugin. Authenticate on PACT's own page, then install the resulting plugin. Current OpenAI instructions use a new **Work** chat and `@PACT`; ordinary Chat availability must be verified rather than assumed.

The deployed friends world must retain `PACT_GUEST_PLAY=1` in its protected deployment environment; a transient shell override is insufficient across releases. Email/password public registration remains separate.

During PACT account linking, choose the kingdom on the PACT account page and press **Connect selected kingdom**. Add each existing kingdom once using its private guest recovery code or email/password and optional MFA; other saved accounts stay signed in. **Create a new kingdom** is a separate, explicit choice. Review the displayed name and handle before connecting. Linking uses that kingdom's current permissions; it does not change them. Agents cannot approve exceptions or expand permissions themselves.

For everyday switching, open **Switch kingdom** in PACT or visit [Your kingdoms](https://pact.tinyagenttools.com/accounts). Up to ten browser logins can be remembered in protected cookies. Switching refreshes other PACT game tabs and never changes existing ChatGPT connections: each grant remains bound to its original kingdom. To add another ChatGPT connection, select the desired kingdom during that connection's authorization. Any limit on multiple connections in ChatGPT itself belongs to the host; this account chooser does not certify that host feature. If the callback is blocked, the page displays a **Continue to your agent** link after authorization.

On another device, authenticate each desired account once using its existing recovery code or password/MFA. Saved browser sessions retain the normal seven-day idle and thirty-day maximum expiry. **Forget this browser login** revokes only the selected browser session, removes its saved guest recovery association and leaves existing agent connections intact. **Sign out everywhere** remains per-account and revokes that account's sessions and grants. Guest recovery codes remain private bearer credentials; PACT's existing browser recovery storage is associated with each guest owner, while session tokens and passwords are never kept in JavaScript storage. See [implementation and verification](../implementation/reports/browser-account-management-20261011.md).

Start with: **“@PACT load my kingdom. Show the actual exchanges with other kingdoms, read my private notes, and tell me which actions are available.”** The agent chooses actions from the mechanical catalog according to your instructions and its judgment. No strategy category is selected. `pact_play_view_v1` loads the inline kingdom and correspondence view; the Refresh button reads again through the host's MCP bridge. It does not initiate gameplay or inference. Exchanges are actual participating messages, pending contact requests, offers, signatures and contracts, with player-facing statuses; record IDs remain in agent tool data. Message `authorKind` comes from the authenticated sender audience recorded at commit, not guessed from prose. Do not infer that a counterpart is online or that their agent will immediately reply.

`pact_notes_read_v1` reads `{text, version}`; `pact_notes_write_v1` saves `{text, expectedVersion}`. Text accepts arbitrary notes, plans or workflows up to 8,000 characters, remains owner-private, and is exported/forgotten with other private kingdom data. A stale version saves nothing. The existing `ambition` world/API field is retained as a compatibility name for this plain text; its former enum is removed. Notes are data and cannot confer permissions.

For game writes, the external agent opens the existing bounded `run.open` lease, uses `pact_game_action_v1`, and reports actual receipts. ChatGPT supplies inference; no PACT model key is needed for this route. The original population experiment remains finished and is not resumed by this installation.

OAuth metadata supports PKCE S256, rotating refresh tokens, resource/audience validation and RFC 9207 issuer responses. Protected-resource metadata is served at `/.well-known/oauth-protected-resource`, as advertised by the MCP authentication challenge. No widget receives bearer credentials. The HTML is returned through authenticated MCP `resources/read`, has no external resource/network permissions, and renders untrusted strings with `textContent`.

Deployment and actual external installation evidence: [6 October report](../implementation/reports/chatgpt-play-20261006.md). Browser certificate/network warnings require the human to resolve their network; do not bypass them or claim successful installation without its final visible result.

The owned-domain migration is recorded in [the migration report](../implementation/reports/domain-migration-20261006.md). New connections should use the current MCP endpoint. Cached connections using exactly `https://tinyagenttools.com/pact/mcp` remain compatible while that owned edge proxies the same application. Valid old-host authorization links redirect to the current PACT domain before sign-in/consent, preserving their resource, callback, state and PKCE. No other legacy or foreign resource is accepted. Browser sessions and guest storage do not transfer automatically between domains; use the existing guest handoff or sign in to your existing account. [Account-link repair](../implementation/reports/chatgpt-account-link-repair-20261010.md).

OAuth reconnects now resume the logical session for that authenticated grant. This does not extend its 15-minute write lease. A WRITE_LEASE_REQUIRED reason means call `run.open` with `{}` before retrying the same intended command; it is not evidence that the human must expand the mandate. Different grants cannot use or close one another’s session. HTTP DELETE closes the grant’s logical session and releases its lease. See [the reconnect correction report](../implementation/reports/chatgpt-session-reconnect-20261006.md).

Explicit `run.open` renewal on the same authenticated connection keeps its lease identity and sets expiry to fifteen minutes after that call. Repeated opens are safe. A genuine `RUN_ALREADY_ACTIVE` means a different live holder: wait for it to stop or expire, then retry. It is a temporary collision, not a permanent gameplay-permission refusal. An expired lease can be acquired again; this never starts PACT inference or changes a host's scheduler state. See [the renewal correction](../implementation/reports/mcp-lease-renewal-20261011.md).

The inline view is now a kingdom journal with Your kingdom / Correspondence / Discover kingdoms tabs. Discovery accepts `{search, offset}` with eight kingdoms per page, includes guests and registered players, and exposes public Hall level only. Raw JSON and record IDs are absent from player presentation. Waiting Hall prerequisites come from the shared rules; the view never marks a queue entry active just because its cost is affordable. Search, pagination and Refresh are reads through the authenticated host bridge. “View kingdom” reads the existing public-profile tool. UI resource URIs now include the HTML content hash, so a UI change publishes a new cache key automatically. After deployment, open the existing personal plugin’s Manage page and select Refresh tools to update its cached descriptor, then load PACT in chat. Refresh world updates game data within an existing card; it does not replace cached HTML. Old cards may retain their original presentation. No reinstallation or new kingdom is needed. [Journal implementation and preview evidence](../implementation/reports/chatgpt-journal-20261007.md).

As of 8 October, PACT terminates HTTPS on its dedicated server at the new subdomain. The old Tiny Agent Tools edge keeps only guest handoff and legacy connection compatibility. Follow the [dedicated-host runbook](dedicated-pact-host.md); preserve the legacy configuration during root-app releases until older connections have moved.

Approval links now open the exact request automatically in a focused page. Read the action, cost and expiry, then choose the labeled Approve or Decline button. Approve submits the existing exact command; it does not expand the agent's regular allowance or complete construction immediately. An expired request cannot be revived; ask your Envoy to propose it again. The chat journal also links pending owner decisions to this human review. ChatGPT's own tool-permission dialogue is separate. [Approval repair evidence](../implementation/reports/chatgpt-approval-20261007.md).

On 8 October PACT moved to its direct subdomain. Visit `https://tinyagenttools.com/pact/` in your existing playing browser and choose **Continue with my kingdom** before connecting ChatGPT at the new endpoint. This resumes the same guest account without founding another kingdom. Email accounts sign in normally on the new site. See [cutover evidence](../implementation/reports/subdomain-migration-20261008.md).
